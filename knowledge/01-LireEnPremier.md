# 📦 PACKAGE QUESTIONNAIRE RGA – MODE D’EMPLOI

Bienvenue dans la documentation du **Questionnaire RGA (Retrait-Gonflement des Argiles)** de TerraStab.

Ce package permet :
- d’auto-diagnostiquer le risque RGA d’une maison individuelle
- d’interpréter un score normalisé sur 100
- de recommander les solutions TerraStab adaptées (Survey / Shield)

## 🔑 POINTS CLÉS À RETENIR

1. **Score sur 100 points**
   - 0–20 : Risque faible 🟢
   - 21–40 : Risque modéré 🟡
   - 41–60 : Risque élevé 🟠
   - 61–100 : Risque très élevé 🔴

2. **TerraStab Survey**
   - Toujours compatible
   - Tous types de fondations

3. **TerraStab Shield**
   - Compatible **uniquement si fondations ≤ 1,50 m**
   - Au-delà → Survey uniquement

4. **Question clé**
   - Profondeur des fondations = décision Shield

5. **Facteur aggravant n°1**
   - Arbres trop proches (< 1,5 × hauteur adulte)
